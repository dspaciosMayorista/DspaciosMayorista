## 3. Implementation (what changed, by item)

**#42 — `lib/calc/cuotas.ts`, `contratos/[numero]/cobros-actions.ts`, `PlanCobroPanel.tsx`, `lib/cuenta/estado.ts`, `app/plan-cobro/[numero]/page.tsx`, new `lib/cobros/recordatorioCuotas.ts`, `lib/notificaciones.ts`.** Design: no schema change. The plan rows still sum to the collection total (so the existing cumulative «cubierta» logic is unchanged), but real payments go to the leading row first and **only the remaining balance is spread over the future installments**; excess is not planned and nothing is negative. `pagado` = Σ `abonos.valor_abono` (already in the collection currency; an annulled abono is gone; a comprobante is not a payment), read with the service client **after** the session-bound contract read and failing closed. `estadoDeCuotas` gives Cubierta / Parcial · falta X / Pendiente with the currency tolerance (0,5 COP / 0,01 USD). USD keeps cents; the panel, the printed plan and the reminders use `formatMonedaDocumento`. Regeneration inserts first and deletes the previous rows after.

**#95 — `lib/catalogo/prefillManual.ts` (pure), `lib/catalogo/cargarCatalogoManual.ts`, `NuevoContratoForm.tsx`, `contratos/nuevo/page.tsx`, `CotizacionManualForm.tsx`, `cotizaciones/nueva/page.tsx`.** Copy-once, editable, text only: choosing a catalog hotel fills **empty** fields only (supplier; category/regime/accommodation when the hotel has exactly one option; with several they are suggestions); never prices, tariffs or validities; badges «del catálogo» / «texto libre» (and for the supplier); restriction chips and an Adults Only warning when the form carries minors. The loader uses the user's own session (RLS), paginates, selects presentation columns only. **Limit (decision for the owner):** nothing is *stored* as a catalog link — the contract and quotation tables keep text. Room category/regime/accommodation for **quotation** rows cannot be saved without a schema + RPC change (`cotizacion_servicios` has no such columns and manual-quotation conversion creates no `contrato_hoteles` row): not built.

**#61 — migration `20260601000331_duplicar_paquete_armado.sql` (+ preflight/postcheck/rollback scripts), `paquetes/actions.ts` (`duplicarPaquete`), `DuplicarPaqueteBtn.tsx`, `PaquetesListado.tsx`, `paquetes/[id]/page.tsx`, `lib/paqueteDinamico/entradaDesdeFilas.ts`, `paquetes/total/nuevo/page.tsx`, `ListadoTotales.tsx`, `paquetes/total/[id]/page.tsx`.**

Atomicity: one `SECURITY INVOKER` plpgsql function (RLS and audit apply; roles superadmin/gerencia/administracion/operaciones). A manual salida that cannot be copied aborts the whole copy. The copy never calls «generate tarifario»; the new package's revision counter is bumped only by its own child inserts.

**#41 — `lib/vuelos/duplicarVuelo.ts`, `NuevoBloqueoForm.tsx`, `NuevoEmpaquetadoForm.tsx`, the two `nuevo/page.tsx`, the two `[id]/page.tsx`, `vuelos/actions.ts`.** `?copiarDe=<id>` prefills a **new** form with configuration only (record blank; no seats, reservations, links or history; states start «pendiente»); dates and windows are a starting point shown with a notice. New order check (return ≥ outbound) on Bloqueo creation. Source is read with the user's session.

**#51 — `contratos/actions.ts`.** (1) `actualizarServiciosContrato`: services **included** in the package no longer enter the reconciliation plan and their costs are added back when the two cost columns are rewritten. (2) `crearContrato`: `asistencia_medica` is also true when an assistance service row is saved (the box alone remains valid for assistance without own cost).

**#33 — `lib/cotizacion/comparativa.ts`, `ComparativaHoja.tsx`, `comparativaAcciones.tsx`.** Read-time presentation only (stored comparatives are immutable): the signed benefit line is folded into the payable child tariff with the already-accepted `plegarNinoGratisItems`; the line is no longer editable text nor printed as a bullet. A fully free child appears as «Niño gratis · Sin costo».
