## 2. B1-05 — what actually happens today (exact current behavior)

Synthetic contract (seed `DTM-9871`, also reproduced in the pg test as `DTM-7011`): 4 passengers (Ana Pérez, Luis Gómez, Marta Ríos, Pedro Soto), two saved air services:
- Service A: BOG→CTG AV871 + CTG→BOG AV872, PNR RV2AAA.
- Service B: MDE→CTG LA881 + CTG→MDE LA882, PNR RV2BBB.

«Voucher de vuelo» creates TWO vouchers (one per service). Voucher A lists only AV871/AV872/RV2AAA; voucher B only LA881/LA882/RV2BBB. **Both list all four passengers**, because the system stores no «who flies which flight». That is the unhidden limitation: it must not be read as «every passenger takes every leg». Before this change the only sign was the small gray note; now a visible notice names the number of services.

Verified in the DB test (R0): the voucher JSON of both services contains the same 4 passengers; `information_schema` has no column on `contrato_pasajeros` matching `tramo|vuelo|servicio`.

### Owner decision requested (NOT implemented — no allocation model introduced)
Should the system record which passenger flies which air service? Concrete proposal if yes:
```sql
create table public.contrato_pasajero_servicio (
  numero_contrato text   not null,
  pasajero_id     bigint not null references public.contrato_pasajeros(id) on delete cascade,
  servicio_aereo  uuid   not null,            -- same key as contrato_vuelos.servicio_aereo
  primary key (pasajero_id, servicio_aereo)
);
```
Decisions needed before building it: (1) granularity: per SERVICE (proposed; matches «one voucher per contracted service») or per leg; (2) default when no rows exist (proposal: keep today's behavior and today's notice); (3) once a contract has any assignment, require every passenger to be assigned to at least one service before generating vouchers? (4) infants follow their `responsable_id` adult? (5) block-origin flights already tie a seat (`sillas`: passenger + record) to a passenger — whether the voucher should read that link instead of a new table (not investigated). Until then the notice is the honest presentation.
