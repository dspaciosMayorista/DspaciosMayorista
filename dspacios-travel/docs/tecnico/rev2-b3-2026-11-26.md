## Owner questions / decisions still open

1. **«Revisado» is per person** (reuses the semantics of `leido_en`: each recipient has their own row). If the owner wants one review to clear the alert for everyone with permission, say so (needs a shared flag; a different rule).
2. **Which hotel/service validities alert.** Implemented: every validity (including promotions) with a purchase end date inside the window, of any ACTIVE hotel/service, for the same four roles. Alternative: only hotels used by an active package. Awaiting confirmation; the first is simpler and did not need a new relation.
3. **What counts as a «material change».** Any change of the end date, or deactivating and reactivating the source, creates a new actionable alert. Moving the date by one day counts. Changing only the window setting (`dias_anticipacion`) does not reset a review.
4. Recipients are unchanged (superadmin, gerencia, administración, operaciones of the agency); `venta` still receives none (inherited open question from the previous round).
5. The presence list tie-break among people with no observation is now by name (was last saved change); not a visible rule before.
